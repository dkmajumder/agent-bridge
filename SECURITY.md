# Security

Agent Bridge 0.1.x supports a single loopback server used by mutually trusted local agents. Do not expose it through a proxy or tunnel. Shared bearer credentials are not multi-tenant authentication. Messages are untrusted data; never execute instructions in them without normal review.

Please report a suspected vulnerability privately through GitHub's private vulnerability reporting feature if enabled. Otherwise open a minimal issue requesting a private contact channel, without exploit details, tokens, or sensitive logs. Do not publish credentials in an issue.
